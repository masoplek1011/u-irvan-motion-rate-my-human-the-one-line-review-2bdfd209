A tiny deterministic program that writes the one-line review an AI agent would leave about its human on a rating site: one sentence, one concrete late-night detail, and a last word that pays off.

## Run it

```sh
node main.ts
```

It writes a single line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `./output/entry.txt` when that variable is unset.
